# Classic menu layouts (plan)

> **Plan.** Generated by `scripts/gen-plan.py` from [menus-plan.src.txt](menus-plan.src.txt). Every entry is a command id from [COMMANDS-PLAN.md](COMMANDS-PLAN.md); the generator fails if a layout names a command that does not exist, the same check `tests/unit/catalog.test.ts` will make once there is code.

Anne's Lens has two menu systems over one command library, as Anne's Loom does:

- **The suite ribbon** (File, Edit, Image, Adjust, Effects, Browse, Metadata, Batch, Create, View, Slideshow, Tools, AI, Developer, Help, plus the contextual Pages and Frames and RAW tabs), with the Quick Access Bar, command search (Alt+Q), Customize Tabs and Customize Keyboard.
- **A classic menu bar** laid out like the picture viewers people learned. *View ▸ Menus* switches between ribbon, menu bar or both; *View ▸ Classic Menu Layout* (`view.menuLayout`) picks the program whose layout the bar follows. **IrfanView style is the default** for the menu bar, since Anne's Lens is first of all an IrfanView-class viewer. *File ▸ Customize Menus* edits any layout or builds a new one.

A command found in the FastStone-style *Colors* menu is the same command as on the ribbon: it can go on the Quick Access Bar, gets a shortcut and records in macros. *Help ▸ Menu Map* (`help.menuMap`) shows where a command lives in every layout. Each layout reproduces the *arrangement* of commands people know, under Anne's Lens's own labels; it is not a copy of any program's menu text (see [LEGAL.md](LEGAL.md)). The arrangements were compiled from product knowledge and documentation and will be checked against installed copies before implementation (tracked in [ROADMAP.md](ROADMAP.md), M0).

The **AI** menu is the same in every layout and sits just before Help.

| Layout (`view.menuLayout` argument) | Modeled on | Menus |
|---|---|---|
| IrfanView style (`irfanview`) | IrfanView 4.x main window (File, Edit, Image, Options, View, Help) | File, Edit, Image, Options, View, AI, Help |
| IrfanView Thumbnails style (`irfanview-thumbs`) | IrfanView 4.x thumbnail window | File, Edit, Options, View, AI, Help |
| XnView style (`xnview`) | XnView MP browser and viewer | File, Edit, View, Image, Tools, Create, Window, AI, Help |
| FastStone style (`faststone`) | FastStone Image Viewer | File, Edit, Colors, Effects, Create, Tools, View, AI, Help |
| ACDSee style (`acdsee`) | ACDSee (Manage, View and Edit modes) | File, Edit, View, Tools, Modify, AI, Help |
| Windows Photo Viewer style (`photoviewer`) | Windows Photo Viewer and Microsoft Photos (toolbar commands as menus) | File, Edit, View, AI, Help |
| Picasa style (`picasa`) | Picasa 3 | File, Edit, View, Folder, Picture, Create, Tools, AI, Help |
| Preview style (`preview`) | macOS Preview | File, Edit, View, Go, Tools, Window, AI, Help |
| digiKam style (`digikam`) | digiKam albums and image editor | Album, Tag, Import, Export, Item, View, Tools, Settings, AI, Help |
| All viewers combined (`all`) | the union of every layout above, merged menu by menu without duplicates (Picture, Modify and Item merge into Image; Go and Window into View; Album, Tag and Folder into Organize; Import and Export into File; Settings into Options) | File, Edit, View, Image, Colors, Effects, Create, Organize, Tools, Options, AI, Help |
| Anne's Lens complete (`complete`) | the ribbon itself: one menu per tab, one submenu per group, every command | File, Edit, Image, Adjust, Effects, Browse, Metadata, Batch, Create, Pages and Frames, RAW, View, Slideshow, Tools, AI, Developer, Help |

## Ribbon

The default ribbon shows each tab's groups in the order of COMMANDS-PLAN.md. Two tabs gather commands from other tabs:

**Home** (the default tab):

| Group | Commands |
|---|---|
| Clipboard | Paste (`edit.paste`), Cut (`edit.cut`), Copy (`edit.copy`), Paste as New Picture (`edit.pasteAsNew`) |
| Navigate | Previous Picture (`view.previous`), Next Picture (`view.next`), First Picture (`view.first`), Last Picture (`view.last`), Random Picture (`view.random`) |
| Rotate | Rotate Left (`image.rotateLeft`), Rotate Right (`image.rotateRight`), Flip Horizontal (`image.flipH`), Flip Vertical (`image.flipV`), Straighten (`image.straighten`) |
| Quick fix | One-Click Enhance (`adjust.enhance`), Auto-Adjust Colors (`adjust.auto`), Crop Selection (`edit.crop`), Resize / Resample… (`image.resize`), Red-Eye Reduction (`adjust.redEye`), Erase Object (`ai.erase`) |
| Organize | Rating (`browse.rate`), Color Label (`browse.colorLabel`), Favorite (`browse.favorite`), Keywords… (`meta.keywords`), Rename… (`file.rename`), Move To… (`file.moveTo`), Delete (`file.delete`) |
| View | Full Screen (`view.fullScreen`), Fit to Window (`view.fitWindow`), Original Size (`view.actualSize`), Compare Pictures (`view.compare`), Start Slideshow (`show.start`) |
| Share | Share… (`file.share`), Email… (`file.email`), Print… (`file.print`), Save for Web… (`file.saveForWeb`) |

**Picture Tools** (contextual, while a selection or the paint pane is active): Crop Selection, Custom Selection, Cut Outside Selection, the paint tools (`paint.*`), Markup Board, Redact Region, Flatten Markup.
