# Anne's Lens command plan — source file.
# scripts/gen-plan.py reads this file and writes docs/COMMANDS-PLAN.md, docs/MENUS-PLAN.md and docs/commands-plan.json.
# Edit this file, not the generated ones.
#
# Syntax
#   @tab <id-prefix> | <Tab name> | <one-line description>
#   ## <Group>
#   <Label> | <id> | <shortcut> | <origins> | <notes>
# Origins are the codes in the legend (ORIGINS below); NEW = an Anne's Lens idea; SUITE = shared with the
# other Anne's Office apps. A note containing "not in tabs" means the command has no default ribbon place.
# Shortcuts are planned defaults; every one can be rebound.
