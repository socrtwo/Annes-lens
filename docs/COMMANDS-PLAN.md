# Command inventory plan

> **Plan.** This is the planned command inventory: every command of the major picture viewers and organizers, tab by tab, with the command id Anne's Lens will use and where the idea comes from, plus commands that are new in Anne's Lens. It is generated by `scripts/gen-plan.py` from [commands-plan.src.txt](commands-plan.src.txt); edit that file, not this one. `npm run catalog` generates [COMMANDS.md](COMMANDS.md) from the command registry, which says what is built so far.

**557 commands** in 17 tabs (91 of them new ideas). Every command will be usable on the Quick Access Bar, on custom tabs, in every classic menu layout ([MENUS-PLAN.md](MENUS-PLAN.md)), on a keyboard shortcut, in a macro and in command search (Alt+Q). Commands marked *not in tabs* have no default place on a tab but are reachable everywhere else, so nothing is hidden.

## Conventions

- **ids** are `area.name` in camelCase, as in the other Anne's Office apps. Where a sister app already defines a command (`file.save`, `edit.undo`, `view.cmdSearch`, `view.qatAddAll`, `ai.setup`…), Anne's Lens reuses the id so shared settings, macros and Quick Access Bar layouts carry over.
- **Arguments.** Some commands take an argument, written `id(arg)` in macros and layouts (`browse.rate(4)`, `file.wallpaper(fill)`, `view.menuLayout(irfanview)`); the notes list the arguments.
- **Shortcuts** are planned defaults. Single-letter keys follow IrfanView where its keys are well known (O, S, T, W, B, I, L, R, H, V, P, C), because people who switch expect them; all can be rebound, and File ▸ Export / Import Settings reads an IrfanView-style key list. The generator rejects duplicate defaults.
- **Origin** says where the command or idea comes from (nominative use; see [LEGAL.md](LEGAL.md)). **new** marks ideas not found in the viewers surveyed (they may exist in other kinds of software); *suite* marks commands shared with the sister apps.
- **Vendor feature names** are replaced with generic terms (Erase Object, Remove Color, Tone Equalizer…).
