# Roadmap

> Milestones are ordered by dependency, not by date. M0 and M1 are done, M2 is under way; the rest is the plan. Each milestone from M1 on ends with a tagged prerelease built for every platform by the release workflow. Command ids refer to [COMMANDS-PLAN.md](COMMANDS-PLAN.md).

- [x] README, feature survey ([INNOVATIONS.md](INNOVATIONS.md)), command inventory ([COMMANDS-PLAN.md](COMMANDS-PLAN.md), generated from [commands-plan.src.txt](commands-plan.src.txt)), classic menu layouts ([MENUS-PLAN.md](MENUS-PLAN.md)), Quick Access Bar plan ([QAT.md](QAT.md)), AI plan ([AI-PLAN.md](AI-PLAN.md)), formats ([FORMATS-PLAN.md](FORMATS-PLAN.md)), recovery ([RECOVERY-PLAN.md](RECOVERY-PLAN.md)), architecture ([ARCHITECTURE-PLAN.md](ARCHITECTURE-PLAN.md)), legal notes, license, contributing guide and issue templates.
- [x] `scripts/gen-plan.py` validates ids, menu references, origins and shortcut conflicts.
- [ ] Verify the classic menu arrangements and default keys against installed copies of IrfanView (current 4.x), XnView MP, FastStone, ACDSee, Picasa 3, Windows Photo Viewer/Photos, Preview and digiKam, and correct [menus-plan.src.txt](menus-plan.src.txt).

## M1 — Shell and viewer (done)

- [x] Project scaffold: TypeScript, Vite, vitest, Capacitor 8 (Android, iOS), Electron, PWA manifest and service worker; CI and release workflows from the sister apps.
- [x] Suite shell: command registry, ribbon, Quick Access Bar with **Add All Choices** (`view.qatAddAll`), Customize Tabs and Keyboard, command search, Backstage, preferences, settings import/export (JSON shared with the suite, plus an IrfanView-style key list), portable mode (desktop).
- [x] **Classic menu bar** with the IrfanView layout (default), every other layout of the plan, and View ▸ Menus / View ▸ Classic Menu Layout. The layouts and the ribbon are generated from [commands-plan.json](commands-plan.json) (`scripts/gen-plan-ts.mjs`), so they cannot drift from the plan.
- [x] Viewer: open (files, folders, recent, drag and drop, paste, *Open with* and *Share to* on every platform), next/previous with prefetch, zoom and fit modes, full screen, rotate/flip (undoable, saved by Save and Save As), information dialog, EXIF viewer, histogram, status bar with pixel info, animation playback, multipage files.
- [x] Codecs: JPEG, PNG, GIF (animated, own decoder), WebP, BMP (platform, then own decoder), ICO/CUR (own), TIFF baseline (own: uncompressed, PackBits, LZW, Deflate, strips and tiles, 1–16 bits, multipage, BigTIFF); platform HEIC/AVIF/JPEG XL/SVG where the engine has them; APNG and animated WebP frames through ImageDecoder where available. Save As: PNG, JPEG, WebP, BMP.
- [x] A catalog test comparing the registry with `docs/commands-plan.json` (every built command is planned, with the plan's label, tab, group and keys; the ribbon and layouts name planned ids only); `docs/COMMANDS.md` generated by `npm run catalog`.
- Not in M1 (deferred): Customize Menus (M3), thumbnails (M3), selections and crop (M3), Save into the same file for formats the app cannot write yet and metadata carried across saves (M2), command-line options (M5).

## M2 — Files, formats and lossless (in progress)

- [x] File operations with the journal: rename, move, copy, delete (Recycle Bin / Trash on the desktop), quick move and quick copy to nine folders, file dates, Undo File Operation (deleted files are restored from the bytes the journal kept). Back ends: desktop, Android Storage Access Framework (which also gives Android Open Folder), the File System Access API in browsers, the iOS Documents folder.
- [x] Save and Save As for every writable format (PNG, JPEG, WebP, BMP, TGA, PPM/PGM/PAM, QOI, WBMP) with options; EXIF, XMP and the ICC profile carried into JPEG, PNG and WebP, the Orientation tag reset when the pixels were turned upright; Save for Web; Save to Target File Size.
- [x] Lossless JPEG transformations (rotate, flip, transpose, transverse, crop at the block grid, grayscale, optimize, keep or strip metadata) for baseline and progressive files; Lossless Auto-Rotate by EXIF; Estimate JPEG Quality; EXIF auto-rotate on display.
- [x] Formats: TGA, Netpbm, QOI, PCX/DCX, XPM, XBM, WBMP, PSD/PSB composite, ICNS, DDS, Radiance HDR, RAW embedded previews, EPS previews (DOS EPS TIFF preview and %%BeginPreview bitmaps), JPEG-compressed TIFF, ZIP/CBZ/EPUB archives as folders. Still to do: AVIF, JPEG XL and JPEG 2000 decoders of the app's own (the platform's are used where present), the rest of TIFF (CCITT, float, CMYK, planar), WMF/EMF, EXR, SVG beyond the platform renderer, PDF pages, 7z/tar/RAR archives.
- [x] Open RAW Pixel Data, Open as Hex, Open as Text; tolerant decoding with the Recovery Report; Open and Repair for JPEG (rebuilt from the coefficients, standard Huffman tables when a table is missing), PNG (CRCs ignored, the app's own inflater decodes to the damage) and GIF; embedded previews carved when the main picture is gone.
- [x] Print at True Size with the calibration ruler; Screen Capture (getDisplayMedia; the desktop answers with the screen); Camera Capture; Open URL.
- [x] Print Setup (paper, orientation, margins, captions), Print Layouts (grids, wallet, 4×6, 5×7, 8×10, contact pages, the folder or one picture), Print Copies and Posters (copies per page; one picture tiled across pages with overlap and cut marks).
- [x] Export Palette (.gpl, .act, .pal, .aco, CSS), Export Metadata as CSV, Export as Icon (.ico, .icns), Export Animation (GIF with a median-cut palette, APNG), Open with External Editor (desktop, nine programs).
- [ ] Scanning on Windows and macOS (needs native WIA / ImageCapture code); Set as Wallpaper; Encrypt Picture; Export as PDF (with Anne's Folio).
- [ ] Tagged prerelease 0.2.0 for every platform.

- Thumbnails window and Browser with folder tree, panes, sorting, filmstrip; IrfanView Thumbnails, XnView, FastStone, ACDSee, Picasa, Preview, Photo Viewer and digiKam menu layouts; Customize Menus.

## M7 — AI

- AI tab and AI menu: setup wizard with separate text/vision and picture services, adapters listed in AI-PLAN.md, capability-based enabling.
- On-device models: erase, background, depth, upscale, denoise, colorize, select subject, embeddings for Search by Content.
- Generate, edit and understand commands; Compare Providers; AI History; Content Credentials on results; Run on Selection with cost caps.
- Several AIs (master and Quaker consensus) for text commands, shared with the suite.

## M8 — Stretch goals

- 8BF plug-in host (Windows), panorama stitching, focus stacking and exposure merge refinements, content-aware resize, vectorize.
- Network-synchronized viewing with the suite's relay; shared albums.
- Stereo and 360° viewing refinements; DICOM and FITS tools.

## Recovery (throughout)

Tolerant decoding comes with each codec. JPEG/PNG/GIF repair arrives in M2, TIFF/WebP/AVIF/HEIC/JPEG XL repair with their codecs, carving (`file.recoverAny`) in M5, fragmented-JPEG recovery in M6. Each method arrives with damaged-file tests.
