# Anne's Lens classic menu layouts — source file, read by scripts/gen-plan.py.
# Every entry is a command id from commands-plan.src.txt; the generator fails if an id is unknown.
#
#   @layout <key> | <menu-bar name in View ▸ Classic Menu Layout> | <modeled on>
#   = <Menu>                 starts a top-level menu
#   > <Submenu>  …  <        a submenu (one level)
#   ---                      separator
#   <command id>
#
# The "AI" menu is the same in every layout and is appended before Help by the generator.
# "All viewers combined" is generated: the union of the layouts below, menu by menu, without duplicates.
